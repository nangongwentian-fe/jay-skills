# 深圳社保电脑端：核实过的页面与案例

核实日期：2026年10月23日；2026年11月13日补充税务电脑端、个缴基数填报与缴费实操。以下来自官方页面观察与官方公开资料。菜单、政策和字段可能变化，执行时读取当前页面。个案字段不代表普遍规则。

## 官方入口与来源

- [个人社保网上服务系统](https://sipub.sz.gov.cn/hspms/)：登录页推荐广东省统一身份认证平台；可能要求用户隐私二次认证。
- [领取失业保险金期间医保代缴说明，2026-05-28](https://hrss.sz.gov.cn/szsi/gzfw/ywzsk/rmwd/content/post_12809806.html)：领取期间职工医保一档（含生育保险）由基金全额代缴。不能据此确认某账户某月已经入账。
- [领取完失业金后医保如何续缴，医保局答复2025-03-05](https://www.sz.gov.cn/hdjlpt/detail?pid=3102829)：相似情形可先办理个缴人员停保，再重新办理灵活就业登记和参保登记并选择险种；支持个人网上服务系统。
- [灵活就业参保登记业务提示](https://hrss.sz.gov.cn/szsi/zxbs/zdyw/gpywcj/lhjyrycbdj/)：扣款协议、险种变更、税务基数申报和缴费。批扣时间及费率应在需要时重新核实。
- [非深户居住登记核验，2026-07-29](https://hrss.sz.gov.cn/szsi/gzfw/ywzsk/sbgx/grcbjf/content/post_12912294.html)：系统自动比对居住登记，无居住证也可凭有效居住登记办理。
- [已有医保增加养老、失业保险，2025-04-18](https://hrss.sz.gov.cn/szsi/gzfw/ywzsk/sbgx/grcbjf/content/post_12123081.html)：介绍直接变更险种，但其情形不能直接替代非深户账户实际显示的限制。
- [2026年医保基数通告，2025-12-29](https://hsa.sz.gov.cn/szsylbzjwzgkml/szsylbzjwzgkml/qt/tzgg/content/post_12574511.html)：2026-01-01至12-31职工医保和生育保险基数下限6727、上限33633；灵活就业费率由7%恢复为8%。
- [调整深圳最低工资标准，2026-08-26](https://hrss.sz.gov.cn/tzgg/content/post_12954870.html)：2026-09-01起月最低工资2700元（粤府函〔2026〕188号）。

公开互动页面中的市民留言是案例陈述，不等同官方答复或适用于所有人的政策。

## 只读查询菜单

| 目标 | 已观察到的路径 | 关键字段 |
|---|---|---|
| 医保现状 | 查询服务 → 参保信息查询 → 基本医疗保险信息查询 | 医疗、生育等险种状态，如“参保（上月已缴费）” |
| 医保累计情况 | 查询服务 → 参保信息查询 → 职工医保参保缴费查询（医疗、生育） | 账户余额、累计月数、连续参保时间；不替代逐月记录 |
| 月度缴费 | 查询服务 → 缴费信息查询 → 五险缴费明细查询 | 设置起止年月，点击查询，切换“医疗缴费明细”或养老页签；核对缴费年月、单位名称、申报原因、金额 |
| 失业核定期限 | 查询服务 → 待遇信息查询 → 失业待遇查询 → 失业保险金查询 | 选择已有待遇申请日期作为查询条件；查看开始月、结束月、待遇状态、核定月数、剩余月数 |
| 发放记录 | 查询服务 → 待遇信息查询 → 失业待遇查询 → 待遇发放信息查询 | 发放时间、待遇项目、金额；未明示所属月时不可自行当成所属月 |
| 参保起止历史 | 查询服务 → 参保信息查询 → 各险种参保历史查询 | 入口说明可查2024年7月后起止年月；本次未验证其结果表 |

表格经常横向溢出：读取完整可访问列标题，必要时横向滚动核对，不能只看截图左侧。点击后出现空弹窗时，等待结果加载再判断。可访问元素点击失败，先检查新状态或截图，再定位；勿盲点旧索引。

## 办理页面观察：仅作条件性参考

### 险种变更

在线办理 → 参保信息变更 → 参保险种变更（个缴人员）。

个案表单显示企业养老勾选、医疗未勾选，并提示：非深户灵活就业人员需重新比对参保（居住）条件，不能直接用此功能办理；应停保后重新登记并选择险种。此限制优先于通用教程，但后续版本可能改变。

该页说明增加险种当月生效、减少险种次月生效，变更后须在税务端重新申报缴费基数。没有在只读查看中勾选或测试提交。

### 个缴人员停保

在线办理 → 个人参保管理 → 个缴人员停保。

字段：“是否当月个人缴费”。当日页面说明：
- 本月由用人单位参保且确认由单位缴费，选“否”。
- 因变更险种需停保后重新办理灵活就业参保，重新选择的险种需本月生效，选“否”。
- 仅需停保者，本月需缴费选“是”，本月不缴费选“否”。

“否”不是当月免缴承诺；需结合重新登记、实际起缴月及税务结果判断。不要将仅停保的规则套到险种变更，也不要据此保证原已缴账目如何处理。

### 重新登记

在线办理 → 个人参保管理 → 灵活就业人员就业登记与参保登记。

失业待遇期内的个案点击此入口时提示“请使用【失业人员灵活就业参保登记】功能操作！”。因此未进入普通登记表单，也未实证停保后普通登记何时开放、每个险种的最终起缴月份。不要声称已验证完整流程，不能用正式停保解除限制来做测试。

### 税务衔接

手机路径：深圳税务 → 我要办 → 社保缴费 → 灵活就业人员申报缴费 → 灵活就业人员缴费基数维护。有效且正常的既有扣款协议通常无需重新签，但仍须核对新险种应缴信息与实际缴费结果。

电脑端已于2026-11-13实测，见下文“税务端页面”。不要把手机路径或外地教程直接当成电脑端菜单。

## 2026 年度基数与费率（2026-11-13 核实）

| 项目 | 数值 | 依据 |
|---|---|---|
| 企业职工养老（灵活就业20%，深户21%） | 下限5521、上限27603 | 广东省2026-10-08公布，2026-07-01起全省统一；2026年1-6月下限5510 |
| 职工医保一档（灵活就业8%） | 下限6727、上限33633 | 深圳医保局2025-12-29通告，2026-01-01至2026-12-31；灵活就业费率2026-01-01由7%恢复8% |
| 深圳月最低工资 | 2700（2026-09-01起，此前2520） | 粤府函〔2026〕188号；已不再作为养老/医保缴费基数下限 |
| 失业代缴医保基数 | 11211（一档，100%在岗职工月平均工资） | 代缴库记账口径；代缴期满后个人参保按下限6727 |

按养老5521、医保6727测算：20%×5521=1104.20，8%×6727=538.16，合计1642.36/月。养老再拆为单位（统筹12%）662.52与个人（个账8%）441.68；医保拆为6% 403.62与2% 134.54。

## 2026-11-13 实测：个缴新增医疗、基数申报与缴费

### 社保端

- 在线办理 → 参保信息变更 → 参保险种变更（个缴人员）：表单“养老/医疗缴费工资”只能填一个数。
- 实测填入远低于两个下限的数字（2750）：业务显示“变更成功”，生效年月回填为个人缴费起始月，变更事项只有“参保险种”“医疗档次”两行，没有缴费工资；已缴月份的缴费基数未被追溯改写，也没有生成重复的个人医疗记录。
- “查看办理结果”页不显示缴费基数；业务跟踪 → 办结业务查询 → 查看明细，对新办结的险种变更提示“该业务未受理”，不能用来查基数。
- 核实基数用：查询服务 → 缴费信息查询 → 五险缴费明细查询，切换养老/医疗页签读“缴费基数”列；参保信息查询 → 基本医疗保险信息查询只看参保状态（如“参保（上月已缴费）”）。
- 关闭业务弹窗会触发“您确定作废当前业务？”，必须取消，不点确定；查询类弹窗关闭无此提示。

### 税务端页面

- 电脑端入口 `https://etax.shenzhen.chinatax.gov.cn:8443/`（443端口主域返回403）。登录选“自然人业务”，需短信或人脸，由用户本人完成。
- 【灵活就业人员缴费基数维护】：快捷选择“缴费基数下限”会按各险种自动填入下限（5521/6727）并显示生效年月；页面红字给出该险种的上下限及依据。
- 自主申报页按“险种×(单位缴纳/个人缴纳)”拆条：2026-11共4条，合计1642.36；历史补差单独成条。
- 缴费可选“协议扣款”（银税三方协议）或“微信扣款”；成功后提示电子税票号与金额。
- 每月21号批量扣费；批扣只扣当月应缴，不补往期差额。

### 补差

- 2026年1-9月养老补差：1-6月每月147元（5510−4775）、7-9月每月149.2元（5521−4775），每条再拆单位/个人两笔（如89.52+59.68）。
- 灵活就业可自愿补缴，不补不影响参保与待遇；系统通常从2月起生成。1月能否补缴为二手转述、未向官方核实，需向主管区局确认。

### 门户与浏览器细节

- “查询服务”在页面顶栏，多数查询项在新标签打开（部分跳转广东人社 ggfw.hrss.gd.gov.cn），也有弹窗形式，需分别处理。
- 五险缴费明细的年月是掩码控件：普通填写不写入，需聚焦后用键盘输入，或在查询条件设置后触发input/change事件；空值会弹“该输入项为必填项”。
- 公众号内打开的税务页面可能是独立窗口，桌面控制工具不一定能挂接，只能截图观察，不能声称读到了DOM。

## 脱敏验收案例

| 场景 | 应有判断 | 禁止结论或操作 |
|---|---|---|
| 本月状态为“参保（上月已缴费）”，明细只到上月 | 当前页面显示参保；本月入账未确认 | 断言本月已缴或已经断保 |
| 核定结束月为M，M+1月有到账 | 核定待遇截止M；到账与所属月不同，查具体所属月 | 宣称待遇延长至M+1 |
| 基金代缴明细含个人与单位金额列 | 结合单位名称、申报原因判断代缴性质 | 把个人金额列说成本人银行卡支付 |
| 非深户变更页要求重登，普通登记又受限 | 报告两项限制，先核实适用入口及接续条件 | 为了看下一页先提交停保 |
| 只查看业务表单，首页未提交数增加 | 告知自动草稿，不等于已办结；不擅自作废 | 宣称完全未产生记录或自动清理 |
| 官方通用教程支持直接变更，但当前账户禁止 | 对照适用人群、来源日期与具体提示，保留疑点 | 机械按教程提交 |
| 页面选择“否”才使新选险种本月生效 | 说明条件及仍需缴费，执行时重核当前说明 | 把“否”解释为当月无需养老医保缴费 |
| 变更成功但结果页不显示基数 | 用缴费明细或税务端核实基数 | 断言填报值已生效 |
| 前端接受低于下限的填报数 | 说明按下限兜底、以税务端为准 | 认为可按填报值缴费 |
| 补差条目未勾选 | 说明自愿、批扣不补往期、不补不影响参保 | 认为会自动补扣或影响待遇 |
| 提示“缴纳成功”只有金额 | 记录电子税票号，约2日后核对到账与基数 | 仅凭“成功”二字断定已入账 |

展示结果时使用简短状态表或流程图；避免把未验证的后续步骤画成已完成。
