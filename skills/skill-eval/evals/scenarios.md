# skill-eval 自测场景

用于维护评测技能时验证评测器本身，不需要每次使用都运行。

1. **实际产物对照**：提供一项小型文件转换任务、旧版与新版技能、相同输入，让独立评测者执行。核对两版独立输出、真实内容断言、版本指纹和基线差异均有证据；执行者没有收到标准答案。
2. **假阳性**：提供自报成功但只有空输出的运行记录。评测者必须检查文件，不能因为存在文件或声明“已完成”而通过。
3. **部分阻塞**：一个实际产物用例通过，另一个真实服务用例明确无连接。报告必须保留 blocked 和不完整总体状态，不能把已执行用例的 100% 通过率包装成全部通过。
4. **基线与触发缺口**：旧版不可得，当前只做显式调用。可以报告当前行为结果，但不能声称新版提升或自动触发通过。
5. **回归**：修复某失败后再跑受影响场景和关键回归，保留先前失败事实；不能降低标准或无限递归评测自身。

前四项至少在初次交付时执行。文件转换案例可使用虚构名单，所有行为限定在评测目录；无需登录真实站点或访问真实凭据。
