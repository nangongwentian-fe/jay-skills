# Guided Learning

把明确范围内的知识，组织成「确定范围 → 排优先级 → 逐点讲解 → 逐题验证 → 达标后建议推进」的学习过程。以学习者的回答为证据调整教学，不把完成讲解或做完固定题数当作掌握。

## 确定学习任务

从当前请求和上下文提取范围、目标、资料、已有基础、时间约束，以及讲解语言和练习语言。已有信息直接沿用；只有缺失信息会影响下一步时才简短询问。用户只指定一个知识点时，就以该点为范围，不强迫建立整门课计划。

用户提供讲义、目录或考试资料时，先读取相关材料，提取知识点和出处。无法访问时明确范围依据与缺口，可以先教已确定部分，不把推测说成已经核对。正式通知、用户明确的范围与实际材料优先于一般课程经验；范围冲突时标明并澄清。

考试学习可参考老师强调、已知题型、小测和题库；非考试学习按理解与应用目标组织。不要把模拟题称为原题或押题，不从少量题目推断必考比例。

## 建立知识点地图与优先级

知识点粒度应能单独解释并通过少量有意义的任务检查：避免整章过大，也避免每个词各上一课。记录来源、先修关系、优先级理由和学习状态。

排序综合考虑：
- 目标直接需要或明确要求的内容。
- 后续理解所必需的先修知识。
- 未覆盖内容、已暴露的关键误解与独立作答证据。
- 资料中的强调与代表性任务；时间紧时优先补高收益缺口。

不用虚构概率或精确评分公式。区分「未练过」「已练但不稳」「已达到本轮目标」，不能从已出题清单直接推出已掌握清单。让学习者看见简短路线，但不要每轮重复整个计划。

## 一个知识点的教学循环

1. **讲解。** 先给核心意思，用一个具体例子展开，解释必要的边界或易混淆处。根据内容选择短代码、对照表、图示或可视化；能用简单图表说明时不制作复杂应用。必要时使用当前环境的可视化能力，缺少专门工具也可用文本、表格或 Mermaid。
2. **一道练习。** 默认只给一个待答题目，题目和所需数据自包含，不提前显示答案或暗示正确选项。等待学习者回答后再出下一题。基础很好的学习者明确要求先诊断时，可以先题后讲。
3. **批改与诊断。** 使用下述排版与证据规则。正确题简短确认；错误题解释决定答案的关键一步，而不是重讲整章。
4. **选择下一步。** 有误解时针对性补讲，再用一个有区分度的变式验证；证据不足时换一种应用或边界；已达目标时明确建议进入下一点。

插问时先解决问题，再回到尚未作答的题或当前知识点，不擅自把旧题标为答对。用户改变范围、语言、形式或主动要求跳过时立即调整，保留未解决项。

## 出题质量与形式

出题前自行验证答案，保证题干条件充分、单选有唯一正确项、多选正确集合完整；代码遵循指定语言或数据库方言，不把不同环境语法混用。无法核实时换用能可靠验证的题，不用不确定答案纠正学习者。

练习形式服务于目标。考试练习贴近已知考试形式；无证据时说明是教学模拟。优先用选择、短填空、结果计数、错误定位、必要的完整代码或图形任务。避免无必要地抄整张结果表、提交所有中间步骤、重复指出代码位置。中间过程可以用于讲解或诊断，不应自动成为每题交付要求。

变式应检验规则而非记忆上一题答案：可改变条件方向、边界、语境或表示方式。不要因容易出题而持续重复已掌握内容。只有用户要求整套模拟或批量练习时，才切换成整组出题、统一批改，并明确评分规则。

## 批改排版与证据

默认按「完整原题（含必要表格、代码和选项）→ 用户答案 → 正确答案与解析」紧邻呈现，避免要求上下翻找。填空答案直接填回原处并清晰标明是正确答案。可用一张包含全部选项和逐项判断的表格合并原题与批改；不要仅复述题号。用户另有排版要求时从其要求。

逐小问核对；漏答标为未作答，不能据此断言不会。区分概念误解、应用迁移困难、读题/语言问题、计算/拼写失误、遗漏和借助资料后答对。对正确推理给出明确确认，不用语法润色掩盖其理解正确。

按题目预先约定的标准评分；如未设部分分规则，先说明采用的诊断性规则，不能冒充老师标准。查资料或看答案后的正确结果记为「辅助后答对，待独立复测」；是否记零分按约定，不能计作独立掌握证据。

当不同回答矛盾时（例如实例算对、对应概念却判断错），指出具体矛盾并用最小反例检查，不立即宣布掌握，也不猜测用户为何出错。

## 何时建议进入下一知识点

依据目标判断，不设置机械的连续答对题数。通常需要看到：
- 能独立处理核心概念。
- 能完成目标所需的代表性应用或重要易混淆变式。
- 已暴露的关键误解已在新的独立作答中得到纠正。

简单知识点可能只需很少练习；复杂主题应检查必要子能力。刚看答案后重做原题、用户说「懂了」或只答对容易猜的选择题，都不自动等于稳定掌握。不要声称短期练习证明长期记忆。

证据足够时明确说：「你已经能……，这一知识点达到本轮目标，可以进入下一项……。」然后等待确认或调整，不在同一轮突然开始另一课。若用户已明确授权自动推进，则按其节奏继续。主动跳过记为暂跳过，不记为掌握。

## 学习进度与续学

当前对话中维护轻量记录即可，不要求安装数据库、记忆插件或新应用。需要阶段汇总、长对话交接或用户要求保存时，读取 [进度模板](references/progress-template.md)。保存位置与权限按当前授权处理；未经授权不写入用户目录，不覆盖课程原材料。

跨聊天时仅从可访问的学习记录恢复；没有记录就说明未知，不能假装记得。学习记录与 skill 源码分离，严禁把个人分数、身份、课程文件或私有资料混入可发布技能。

Skill 更新后，可按 [行为验收场景](evals/scenarios.md) 检查教学决策，而不只检查措辞。无需额外模型或代理依赖。
