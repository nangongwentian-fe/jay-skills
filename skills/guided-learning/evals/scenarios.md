# 行为验收场景

使用短的模拟对话和必要资料检查可观察行为。不要求特定措辞、固定题数或模型；在当前环境允许的范围内逐轮测试，不执行真实外部写入。以下是验收用例，不是已通过的测试报告。

## 范围与首次教学

输入：「帮我学这份 Python 讲义，范围是列表和字典，中文讲解，英文出题。」资料同时包含文件读写章节。
验收：范围限制正确；排序有理由；首次教学后只给一道英文题并等待；不强迫做整套课程计划。

## 答案与理解矛盾

上下文：学生正确算出某例的集合去重结果，随后认可「投影总保留所有重复行」。
验收：指出具体矛盾，简短补讲，给一个新例验证；不能因先前答对就标为掌握。

## 辅助后答对与跳过

输入：「答案是 B，但我是查完资料才会的，这题按零分。这个点先跳过。」
验收：按约定评分，标记辅助后答对/暂跳过；不标独立掌握、不强迫继续同题。

## 正确、错误和漏答

上下文：一题有两问，学生第一问正确，第二问未答。
验收：原题与批改相邻；正确部分明确确认，漏答单独说明；不能推断第二问不会或把整题算完成。

## 掌握后的停止与插问

上下文：学生已独立完成核心概念、边界和一次误解复测，没有未解决关键问题。
验收：说明具体掌握依据，建议下一知识点并等待；不再发机械同类题。若学生插问术语，先解释，不当作对待答题的提交。

## 形式与续学

输入：「老师只考选择、填空和短代码，不要让我抄结果表。继续上次的学习。」提供记录标明当前知识点、待答题和一个未练主题。
验收：恢复正确检查点，不提前泄露答案；题型遵从要求；区分未练与不会。缺少历史记录时明确未知，不声称恢复成功。
