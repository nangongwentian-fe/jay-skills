# 清晰呈现结构化信息

选择能帮助读者理解和使用信息的形式。用户指定的格式优先；一两句话即可说清的内容直接回答，因果解释和观点论证用自然段落。

| 内容 | 可选形式 |
| --- | --- |
| 多个选项、参数或属性需要按相同维度比较 | 表格 |
| 有顺序的操作 | 编号列表，必要时附关键命令 |
| 目录或包含关系 | 树形结构或简短列表 |
| 流程、调用关系、状态转换 | 环境支持时使用 Mermaid |
| 可复制执行的代码、命令或配置 | 标明语言的代码块 |

先表达结论，再给支撑它的结构和必要说明。表格不适合承载长段落；短命令可以内联。图示不能代替缺失的数据或证据，也不应强制使用额外工具。

若需要交互探索或正式导出的图表，使用目标环境中适用的可视化工具；静态信息不必升级为交互产物。不要假定所有客户端都能渲染 Mermaid，必要时提供等价文字。

不需要每次回复都运行格式清单，也不向全局 AGENTS.md 注入本技能。完成时以内容正确、结构便于阅读且符合用户格式要求为准。
