# 岭南大学课程数据查询

## 入口与范围

- 学校是韩国 영남대학교 / Yeungnam University，不是香港岭南大学。
- 学生 URP 入口：`https://std.yu.ac.kr/std5/websquare/websquare.jsp?w2xPath=/std5/cm/main/index.xml`。从当前页面菜单核实入口；失效时通过学校官网导航查找，不猜内部接口。
- 开课数据入口：**수업관리 → 시간표/수업계획서조회**（课程管理 → 课表／教学计划查询）。**교육과정조회** 是培养方案查询，不可用其课程目录代替实际开课班次。
- 使用当前环境支持的已授权浏览器连接，优先复用用户现有 Chrome 登录会话；遵循用户的浏览器偏好。需要登录时由用户输入密码，不读取或搬用 Cookie、Token、浏览器配置目录。
- 课程查询请求不包含选课、需求调查提交或个人信息修改；这些操作另按用户的明确授权处理。

## 明确查询条件

从用户请求和当前页面确认年份范围、学期、学院、学部、专业与年级。用户只说“所有学期”时，先查已明确年份内的全部学期，同时询问年份范围，不无限回溯历史。年份明确后覆盖每一组合，包含 **1、여름、2、겨울**（第1学期、夏季、第2学期、冬季）。

计算机工学的已验证筛选路径是 **디지털융합대학 → 컴퓨터학부 → 컴퓨터공학전공**；这是定位起点，按目标年度实际选项核实。年级设为 **전체** 才覆盖全部年级。不要把其他专业的同名课程混入；若用户要包含学部共同课程，另查对应的 **컴퓨터학부** 选项并记录课程归属。专业结果不含某年级时，不能直接宣称该年级没有课程。

## 逐学期查询

1. 输入年份并使编辑生效，选择学期。**切换年份或学期可能异步重建学院、学部和专业选项**，屏幕还可能暂时保留旧值。
2. 读取新的页面状态，等待加载结束，再依次选择学院、学部、专业。每个层级变化后检查下一级选项。不要在切换学期后立即沿用旧专业条件点击查询。
3. 点击 **조회** 前，确认目标年份、学期、专业和年级均已生效；点击后等本次查询完成，再读取结果、提示和计数。旧表格或旧计数可能在加载期间继续显示。
4. 按下表记录状态。结果为0或学期不可查询时，也保留该组合的查询记录。

| 页面证据 | 查询状态 | 结果数量 |
| --- | --- | --- |
| 查询完成、表格有数据、`[건수:N]` | 有结果，继续完整采集 | N |
| 查询完成、`[건수:0]`、`데이터가 없음` | 本次条件返回0条 | 0 |
| 弹窗 `조회할 수 없는 년도,학기입니다.` | 该年度学期无法查询 | 留空，不能写0 |
| 超时、登录失效、筛选未生效或页面错误 | 查询未完成 | 留空，并写具体原因 |

学院列表为空时先检查加载状态。加载完成后可点击查询查看系统提示；不能因无选项就把前一学期的0条结果记到当前学期。关闭已读提示后继续下一个明确的组合。同样的访问或登录障碍反复出现时保留已采集结果并说明受阻范围。

“0条”和“无法查询”都不能推断为最终不开课，也不能据此断定学校尚未发布。未来学期不使用往年课程、教师或时间填补。

## 完整采集与核对

表格可能是虚拟滚动：DOM 只维护一部分行，隐藏行还可能保留旧内容。不要把一次 DOM 快照、`innerText` 或第一屏当作完整结果。

- 需要操作或采集该表格时，读 [URP 页面与采集参考](references/urp-capture.md)。使用当前浏览器文档允许的页面读取和滚动能力，不直接调用页面内部数据对象或私有接口。
- 只采集已渲染且可见的完整课程行。逐段滚动并保留重叠，每次等表格更新后再读；按 **学年＋学期＋选课编号（수강번호）** 去重。页面另有区分班次的标识时一并保留。
- 同一课程的不同选课编号、分班不能按名称合并。同一编号在不同学期也不能合并。
- 重叠行应核对课程、教师、班级、时间、教室和学分。若有不一致，等渲染稳定后重新读取对应行，不静默覆盖。
- 每学期去重行数必须等于本次页面的 `[건수:N]`。数量不足时继续滚动或使用页面实际提供的完整导出；数量超出时检查是否混入旧学期或隐藏行。无法对齐时交付已采集数据并标明不完整，不能宣称全部导出。

## CSV 交付

用户请求导出时，生成课程明细 CSV；跨学期查询另附查询记录 CSV，使0结果、无法查询和失败的组合也能追溯。

- 明细每行一个班次，至少包含：学年、学期、年级、课程类别、选课编号、韩文课程名、任课教师、班级、上课时间、教室、学分、查询专业、查询日期、来源网址。按需保留授课方式、开课专业、备注及名额等实际字段。
- 查询记录包含：学年、学期、查询条件、状态、页面结果数、实际导出数、系统提示／失败原因、查询日期和来源。
- 不导出学号、联系方式、登录资料或无关个人信息。教师姓名可保留，个人内部编号通常无需导出。
- 保留韩文原名及原始时段。只清理显示折行、非断行空格等排版字符；多个上课日和教室仍需可区分。缺失值留空，不推测补齐。中文译名如有需要另列。
- 使用标准 CSV 引号转义及 UTF-8 BOM，保证中韩文可被 Excel 正确识别。编号和班级属于标识，保留前导零；提示用户用文本列导入，以免电子表格自动转换。不要用公式伪装文本。
- 重新读取最终 CSV，检查列数、关键字段、唯一键，以及各学期记录数与网页计数一致；核对查询记录覆盖全部目标组合。
- 最终答复提供文件链接、查询范围、各状态摘要和实质性缺口。时间和查询日期按 **Asia/Seoul**；历史案例和技能编写日期不是当前查询日期。
