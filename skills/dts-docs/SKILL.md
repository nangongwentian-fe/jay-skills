# DTS 官方文档查询

在回答 DTS 的产品用法、配置、接口或故障问题前，先查匹配产品与版本的官方文档。已有同一会话中读取的适用页面可以复用；涉及更新、不同版本或未覆盖的接口时再查询。不要仅凭旧项目代码或经验推断产品要求。

## 识别产品与版本

结合用户明确说明、当前问题、项目引用的 SDK、配置、日志及安装包信息判断，不因仓库使用 DTS 就对无关功能加载文档。

- 区分服务端产品版本与前端 SDK 版本；它们可能不同。`ac_conf.js` 路径、旧类名和源码注释只是线索，不独立证明运行版本。
- 用户提供某版本文档时先读该文档；本地证据不一致时指出差异。
- 版本未知时先检查可访问的项目证据。必要时询问版本，同时继续不依赖版本的定位；不要默认为最新版本。
- 云渲染前端通常同时涉及 **Cloud + SDK**：服务部署查 Cloud，播放器参数和场景 API 查 SDK。不要将整个项目固定路由到某一本手册。

## 选择文档入口

总入口：[DTS 文档中心](https://doc.freedo3d.com/)。从首页版本导航进入目标版本，再跟随产品与章节链接。下面是已核实的 7.0 入口（2026-10-29）；其他版本或链接失效时从首页重新发现，不通过替换 URL 中版本号猜链接。

## 查询与核实

使用当前可用的网页读取、搜索工具，不绑定某个插件。优先读取已知页面与站内链接；页面只是目录时继续打开相关章节，不能用目录代替接口证据。找不到内容时用 `site:doc.freedo3d.com` 加产品、版本、接口名或错误码搜索，并打开结果正文。

对配置和 API，核实字段名、必选性、默认值、参数所在对象、回调时机及适用版本。代码变更前，同时核对项目实际加载的 `ac.min.js`、随包示例或类型声明；文档有某能力不代表当前 SDK 已支持。

- 区分文档明确规定、示例用法和本地实现行为；文档没有提及不等于明确不支持。
- 历史版本文档和更新记录可解释迁移，不与目标版本参数静默拼接。
- 当前文档与本地 SDK 有差异时分别给出证据，按用户实际环境选择适配方式，不自动升级 SDK。
- 读取失败可尝试其他可用读取工具、官方站内搜索或本地随包资料。仍无法确认时说明缺失证据，不编造 API，也不把搜索摘要当作完整规格。

## Cloud / SDK 接入排查要点

遇到 `ac_conf.js`、`ws://undefined` 或播放器连接问题时，沿“HTML 加载配置 → 全局配置字段 → 应用拼接地址 → SDK 构造参数 → 实际请求”的链路检查。

分别确认播放器连接和管理连接的用途。不要因为旧应用先连 `/manager` 就认定所有 Cloud 接入都必须提供 `Manager`；也不要因一个直接连接示例就删除用户需要的管理功能。按目标版本示例、本地 SDK 和用户需求决定。

注意 `HostConfig.UseHttps` 等应用配置与 SDK 的 `options.useHttps` 属于不同层；检查应用是否实际传递。`AirCityPlayer` 等兼容名称是否可用，以实际加载 SDK 为准。SDK 支持的实例/工程选择、事件和重连能力应优先复用。

## 输出

先给结论和适用的产品/版本，紧邻关键说明提供具体官方章节链接。涉及项目问题时指出相关配置或代码位置，区分文档核实、静态检查、模拟测试和真实服务验证。

查文档不自动授权部署、重启服务、修改远端实例或安装工具；按用户当前任务范围行动。
